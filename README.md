# salesforce-training
Salesforce Training
This repository contains projects and modules completed as part of my Salesforce development journey, focusing on CRM fundamentals, object modeling, and administrative tasks.

🚀 Overview
The primary goal of this repository is to document the transition from conceptual CRM models to functional Salesforce implementations.
This repository documents my progress in mastering the Salesforce platform, specifically focusing on CRM architecture and data management. It highlights a College Admission System project that demonstrates how to map real-world business processes to standard and custom Salesforce objects. The work showcases expertise in data modeling, including the implementation of relationships and field-level configurations, alongside a solid understanding of Salesforce security protocols like Profiles and Permission Sets. By tracking completed Trailhead modules and documenting hands-on exercises, this project serves as a professional portfolio of my foundational Salesforce administration and development skills.

📂 Projects Included

1. College Admission System (CRM Mapping)
A project that maps standard Salesforce CRM objects to a Higher Education use case:
Accounts: Representing Colleges or Universities.
Contacts: Representing Students and Applicants.
Opportunities: Representing Admission Applications
Leads: Prospective students interested in programs.

2. Trailhead Modules
Documentation and notes from various Trailhead learning paths, including:
Salesforce Platform Basics
Data Modeling & Management
Lightning Experience Customization
User Authentication and Security

🛠️ Tech Stack
Platform: Salesforce (Developer Edition / Sandbox)
Tools: Trailhead, Salesforce Lightning Inspector, VS Code (Salesforce Extension Pack)

📖 Key Learnings
Understanding the difference between Production and Sandbox environments.
Cofiguring custom objects, fields, and relationships (Master-Detail vs. Lookup).
Implementing automation using Flow Builder.
Security settings: Profiles, Permission Sets, and OWDs
